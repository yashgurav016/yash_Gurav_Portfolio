# Yash Gurav - Portfolio

Static website (HTML + CSS + JavaScript). No build step or backend needed.

## Folder structure
```
Yash_Gurav_Portfolio/
├── index.html              <- open this file
├── Yash_Gurav_Resume.pdf   <- resume (View + Download buttons use this)
├── css/style.css           <- all styling (dark + light theme)
├── js/script.js            <- animations, theme switch, typing text
└── images/                 <- profile photo + certificates
```

## How to run
- Double-click `index.html`, or
- VS Code: open this folder > right-click `index.html` > Open with Live Server.

## Notes
- Opens in dark mode by default; visitors can switch to light with the toggle.
- To replace the resume, keep the file name `Yash_Gurav_Resume.pdf`.
- Fonts load from Google Fonts, so internet is needed for the full look.
